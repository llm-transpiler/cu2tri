# 内核开发服务器 - 快速使用指南

## 🚀 快速开始

### 1. 配置验证
```bash
cd /workspace/monocases/server/kernel
python config/integration_config.py
```

### 2. 运行测试（使用GPU 5）
```bash
# 运行所有测试
python run_tests.py --gpu-id 5

# 只运行GPU 5专项测试
python run_tests.py --gpu5

# 只运行基础测试
python run_tests.py --basic

# 只运行集成测试
python run_tests.py --integration
```

### 3. 启动服务器
```bash
# 启动完整服务器（包含集成测试）
python start_kernel_server.py

# 跳过集成测试启动
python start_kernel_server.py --skip-tests
```

### 4. 运行演示
```bash
python demo.py
```

## 🌐 API接口

启动服务器后，可以通过以下接口使用：

- **API服务器**: http://localhost:8000
- **健康检查**: http://localhost:8000/health
- **API文档**: http://localhost:8000/docs
- **交互式文档**: http://localhost:8000/redoc

### 主要API端点

```bash
# 编译内核
curl -X POST http://localhost:8000/compile \
  -H "Content-Type: application/json" \
  -d '{"kernel_type": "triton", "source_code": "..."}'

# 测试内核
curl -X POST http://localhost:8000/test \
  -H "Content-Type: application/json" \
  -d '{"kernel_name": "my_kernel", "test_inputs": [...]}'

# 性能测试
curl -X POST http://localhost:8000/benchmark \
  -H "Content-Type: application/json" \
  -d '{"kernel_name": "my_kernel", "input_sizes": [...]}'

# GPU状态
curl http://localhost:8000/gpu/status

# 队列状态
curl http://localhost:8000/queue/stats
```

## 🚨 故障排除

### 常见问题及解决方案

1. **GPU不可用**
   ```bash
   nvidia-smi  # 检查GPU状态
   python -c "import torch; print(torch.cuda.is_available())"
   ```

2. **编译失败**
   ```bash
   nvcc --version  # 检查CUDA版本
   python -c "import triton; print(triton.__version__)"
   ```

3. **API密钥问题**
   ```bash
   export OPENROUTER_API_KEY="your_key"
   export GEMINI_API_KEY="your_key"
   ```

4. **端口占用**
   ```bash
   lsof -i :8000
   kill -9 <PID>
   ```

## 📈 性能优化建议

1. **GPU使用优化**
   - 使用生产环境GPU (2-5) 进行性能测试
   - 开发时使用开发环境GPU (0-1)
   - 监控GPU温度和内存使用

2. **编译优化**
   - 启用编译缓存
   - 使用适当的优化级别
   - 批量编译相关内核

3. **测试优化**
   - 使用warmup运行预热GPU
   - 选择合适的测试规模
   - 并行运行无关测试
