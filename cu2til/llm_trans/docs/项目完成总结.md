## 📚 完整的测试用例接口约定

### 必需文件

每个测试用例目录包含：

```
algorithm_name/
├── triton_/kernel.py       # Triton 实现
├── torch_/ref.py           # PyTorch 参考
├── get_data.py             # 数据生成
└── check_cute.py           # 测试脚本（从 tools 复制）
```

### get_data.py 接口（统一）

```python
def get_triton_torch_inputs(params):
    """
    生成测试数据
    
    Returns:
        tuple: (triton_inputs, torch_inputs, output_tensors)
        - triton_inputs: list of inputs for Triton/CUTE kernel  
        - torch_inputs: list of inputs for PyTorch kernel
        - output_tensors: list containing output tensor
    """
    # 创建输入
    input_a = torch.randn(..., device='cuda')
    input_b = torch.randn(..., device='cuda')
    output = torch.empty_like(input_a)
    
    triton_inputs = [input_a, input_b, output, ...]
    torch_inputs = [input_a, input_b, ...]
    output_tensors = [output]
    
    return triton_inputs, torch_inputs, output_tensors

# 兼容性
get_cuda_torch_inputs = get_triton_torch_inputs
```

这与 `checker.py` 中使用的接口完全一致！
